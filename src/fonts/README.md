# فونت

فونت **آهنگ** (Ahang) از فونت‌ایران، طراح: مسلم ابراهیمی. دو وزن Regular و DemiBold از روی فایل‌های TTF به woff2 تبدیل شده‌اند.

این فونت رایگان و آزاد نیست و بر اساس متن داخل خود فایل، استفاده‌اش مجوز فونت‌ایران می‌خواهد (https://fontiran.com/licenses). مجوز MIT این ریپو شامل آن نمی‌شود.

پیش از انتشار عمومی (گیت‌هاب، فروشگاه‌ها) مجوز مناسب را بگیرید. اگر نگرفتید، این دو فایل را بردارید: افزونه بدون خطا کار می‌کند و Tahoma جایگزین می‌شود.
